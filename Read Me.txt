MAC STL REPAIR
==============
By Dave Tries This  -  youtube.com/@davetriesthis
Latest version:     https://rebrand.ly/stlrepair

Fixes 3D-print files that a slicer rejects - holes, non-manifold edges,
flipped normals, stray fragments. No file size limit. Everything runs on
your own Mac; nothing is uploaded to the internet.


INSTALL
-------
Drag STL Repair onto the Applications folder shown next to it.
Then open it from Applications or Launchpad.


HOW TO USE IT
-------------
  - Drag STL files onto the window, or click "Choose Files".
  - Several at once is fine; they queue up.
  - Repaired files are saved to:  Downloads / STL Repaired
    with "_repaired" added to the name. Nothing is ever overwritten -
    a second repair of the same file becomes "_repaired_2".
  - Your original file is never changed.
  - "Show in Finder" jumps straight to the result.
  - Quit with Command-Q when you are done.

A 90 MB file takes a few seconds. Very large or badly damaged files can
take several minutes - the line under the filename keeps updating to show
what it is working on, so you can tell it has not stalled.


READING THE RESULTS
-------------------
Each file lists, in plain language, what was actually fixed - holes
closed, non-manifold edges resolved, stray fragments removed, normals
rebuilt, junk triangles discarded.

A green tick means the result is watertight and ready to slice.
An orange warning triangle means something survived the repair - the file
is still usable, but look it over before printing.


THE ORANGE NOTE
---------------
If you see a note about triangles being added, read it.

Closing a hole means inventing new surface. The app closes holes
plausibly, but it cannot know how the original surface actually ran. If a
large chunk was missing, check that area looks right before committing to
a long print.

A note about VOLUME CHANGE on an already-closed model is a stronger
warning: the repair altered the actual shape. Inspect before printing.


FILE TYPES
----------
Reads STL - both binary and ASCII.
Always writes standard binary STL.

(Earlier versions also read OBJ, PLY, OFF, 3MF and GLB. If you need one
of those, convert it to STL first, or ask David for the older build.)


IF IT WILL NOT OPEN
-------------------
This app is built for Apple Silicon Macs (M1 and later). On an older
Intel Mac it will not launch. Ask David for a rebuild.
